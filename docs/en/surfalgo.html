Classes of surfaces.

Surface classes.

The following surface classes exist in ZenCad:

  • Face
  • Surface

Find normal

Returns a Vector3 normal at parameters u, v. Face.normal() defaults both parameters to zero; Surface.normal(u, v) requires both parameters.

Сигнатура:

face.normal()
surface.normal(0, 0)
