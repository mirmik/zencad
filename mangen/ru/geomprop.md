# Геометрические характеристики.
Раздел посвящен измерению геометрических характеристик конструируемой геометрии.

Геометрические расчёты используют единицы модели: объём измеряется в кубических единицах. Экспортёры STL/STEP/3MF считают исходные координаты миллиметрами. Для физической массы умножьте объём на плотность в согласованных единицах.

----------------------------------------
## Встроенные методы
Shape имеет ряд методов, позволяющих запросить геометрическую информацию.

----
### Центр масс.
```python
shape.center() # -> Point3
```

----
### Объём.
```python
shape.mass() # -> Scalar
```



## Пример

`mass()` для тела возвращает объём как `Scalar`, `center()` — центр масс как `Point3`. Метод `.value()` получает число или кортеж координат.

```python
import zencad as z

body = z.box(2, 3, 4)
volume = body.mass()
center = body.center()
assert abs(volume.value() - 24) < 1e-7
assert all(abs(a - b) < 1e-7 for a, b in zip(center.value(), (1, 1.5, 2)))
```

Для площади и суммарных свойств видимой сцены используйте [inspect](headless.html), для габаритов — [ограничивающую коробку](bbox.html).
